# Our Shared World

MASTER PROMPT — Private Couples App “Our Space”

Create a polished, modern, private iOS application for couples called “Our Space”.

The app should feel like a combination of a shared bucket list, life planner, date idea app, memory journal, places/food wishlist, couple competition tracker, and private relationship space.

The goal is NOT to create a generic todo-list app. It should feel personal, fun, romantic, playful, and something a couple would genuinely keep using for years.

1. Core concept

Each user creates an account.

A user can create a private Couple Space and invite their partner using a secure one-time invitation link or code.

Example:

Partner ❤️ Partner

Only the two members of that Couple Space can access its content.

Other users of the application must NEVER be able to see another couple's:

plans

photos

memories

scores

locations

bucket-list items

restaurants

notes

future goals

activity history

All backend authorization must enforce this rule. Do not rely only on hiding data in the UI.

Support Face ID / biometric locking as an additional privacy feature.

Privacy is extremely important.

Implement:

27. Product philosophy

The main question while designing every feature should be:

“Will this make two people want to open this app again?”

Do not build unnecessary social-media functionality.

No public profiles.

No followers.

No public feed.

No likes from strangers.

No discovery of other couples.

This is intentionally a private space for two people.

The application should become more valuable over time.

After several years it should contain:

hundreds of memories

places they visited

their competition history

trips

restaurants

photos

completed bucket-list items

future dreams

relationship milestones

It should ultimately feel like a digital archive of their life together, while still being useful every week for answering:

“What should we do?”

“Where should we go?”

“What did we want to try?”

“Who's winning in tennis?”

“What have we done together?”

Build the application around that vision.

Prioritize the first production MVP in this order:

Authentication + private Couple Space

Partner invitation

Home dashboard

Activities / Our List

Plans

Us vs Us + score history

Places & restaurants

Memories + photo uploads

Date Jar / Random Adventure

Timeline

Calendar

Stats

Map

Future/Someday goals

Polish, animations, widgets and advanced features

Do not treat this as a demo. Structure the project so it can evolve into a real App Store application.
